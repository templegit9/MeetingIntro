### Fixes

**Switching to Microsoft Graph no longer shows an empty calendar.** If you had chosen which calendars to monitor while on EventKit and then switched the provider to Microsoft Graph, you'd see no events at all. The two systems identify calendars completely differently, and the app was applying your EventKit selection to Graph, which matched nothing. Your selection is now remembered separately for each provider, and your existing choices carry over.

**Crashes now leave an explanation behind.** A crash report tells us where an app stopped but not what it complained about, which makes some failures a guessing game. MeetingIntro now records the exception's message and stack to `Diagnostics/crashes.log` alongside the usual logs, so a crash can be diagnosed from the file instead of reconstructed.

Also hardens the ticker against a layout-timing issue that matches the shape of a reported crash.
