MeetingIntro is now on the **Mac App Store**. The Homebrew version stays free and stays exactly as it is — this release is the three bugs that shipping it uncovered, all of which were in your copy too.

### A calendar that went quiet stayed quiet

If a secondary calendar source lost access — a flaky Keychain read, a Microsoft token that needed refreshing — it was never asked again, so that account's meetings silently vanished until you restarted the app. It now asks once per launch and comes back on its own. Interactive sign-ins are still never triggered from a poll, so switching tabs can't ambush you with a login.

### Recordings you can actually find

Recording saved to `~/Movies/MeetingIntro/` unless you'd picked a folder. That was fine here, but the sandboxed App Store build resolves the same path to a hidden container nobody can reach — and the transcripts and notes went in there with the audio. The save location is now explicit, and the App Store build asks where you want files before it records anything.

### The About box can count

It read "© 2,026". SwiftUI formats a bare number with your locale's thousands separator, and a year is not a quantity.

---

Nothing else changed. If you're on Homebrew, `brew upgrade --cask meetingintro` or use the in-app updater; if you'd rather buy it on the App Store, it's there at $14.99 and the two are the same app.
