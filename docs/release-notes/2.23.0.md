Google Calendar is now a calendar source of its own — and the reason isn't reading.

macOS Calendar has always brought your Google events in, so nothing was missing. What was missing was the ability to *reply*: Apple gives apps no way to accept or decline an invitation, so every Gmail invitation MeetingIntro showed you was something you had to go and answer somewhere else.

Connect Google directly under Settings → Calendar and those invitations get real Accept, Tentative and Decline buttons, the same as Microsoft 365 ones. If your Google account is also set up in macOS Calendar — it almost certainly is — nothing changes about how your events appear or which reminders fire; only the reply takes the new path.

**Proposing a different time still won't appear for Google invitations.** Google Calendar has no counter-proposal concept at all, in its API or its own interface, so rather than offer a button that would quietly drop the time you picked, there simply isn't one.

### Setting it up

Google requires the OAuth client to belong to you. Unlike Microsoft, an app can't ship one for other people to use without passing Google's verification review, which caps it at 100 users in the meantime — so MeetingIntro would break for the hundred-and-first person with no way for them to fix it. Settings → Calendar → Google Calendar → Account has the direct link to create one, and names the one setting people get wrong: choose **iOS** as the application type, not Web application.
