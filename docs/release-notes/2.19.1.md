### Fixes

**Scrolling the dropdown feels smooth again with the new height option turned off.** v2.19.0 measured the list's content height even when "Fit dropdown height to content" was disabled, which meant a state update on every layout pass — so the default dropdown picked up a stutter while scrolling that it never had before. The default path is now exactly what it was prior to v2.19.0, untouched.
