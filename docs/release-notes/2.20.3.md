### Fixes

**Switching the calendar provider no longer throws a sign-in at you.** Selecting Microsoft Graph immediately popped up "MeetingIntro wants to use microsoftonline.com to Sign In", before you'd asked to sign in to anything. The app now waits for you to press **Sign in with Microsoft** and simply says what it needs until then.

This was a side effect of the new one-click sign-in: the old flow only displayed a code, so the same background check went unnoticed. Opening a browser and a system consent sheet is not something an app should do on its own schedule.
