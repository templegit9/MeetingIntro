## Subscribing to a calendar by URL actually works now

Settings → Calendar → **Subscribe to a Calendar by URL** takes an internet calendar link (`.ics` / `webcal`) and hands it to macOS Calendar. Two faults made it look broken, and together they made it look broken in a way you couldn't recover from.

**The box vanished.** It was only shown when EventKit was also the target for *creating* events. Those are unrelated — subscribing is something macOS Calendar does, and it works whenever macOS calendars are switched on. So the moment you chose Microsoft 365 or Google under "Create new events in", the box disappeared, with nothing wrong and nothing to explain it. It now stays visible whenever macOS calendars are on. The Microsoft 365 verification and invitation settings were hidden by the same mistake and are fixed too.

**The calendar you subscribed to never showed up.** MeetingIntro checked for it 2.5 seconds after handing off — while Calendar.app's subscribe sheet was still open and you were still choosing where to put it. It found nothing, and there was no way to make it look again: the "Load Calendars" button only appeared when the list was empty.

Now the list loads as soon as you open the tab, there's a **Refresh** button beside "Calendars to Monitor" that's always there, MeetingIntro notices the moment macOS commits the subscription, and after a hand-off it keeps watching for up to two minutes — telling you it's waiting rather than sitting silent.

You can add several calendars one after another; the box clears and is ready for the next link each time.

One thing worth knowing: a newly subscribed calendar is only monitored automatically if you haven't ticked specific calendars. If you have a selection, tick the new one when it appears.
