### Fixes

**Sign in with Microsoft works again.** Signing in failed with *"AADSTS900023: Specified tenant identifier 'auth' is neither a valid DNS name, nor a valid external domain"* for anyone using the built-in app registration, which is everyone who has not created their own in the Azure Portal. The app was sending its redirect address where Microsoft expects the application ID, so Microsoft read part of that address as the name of a company and rejected it. The correct application ID is now sent. This affected 2.20.1 through 2.20.4.

The Client ID box under **Use my own Azure app registration** now also checks what you paste. An application ID is a GUID from your app registration's Overview page, and anything else is refused with an explanation and falls back to the built-in registration, rather than sending you to a Microsoft error page. The box also shows only what you typed, instead of displaying the built-in ID as though you had entered it.
