The other dropdown style can answer invitations too.

If you use the compact menu style (Settings → Menu Bar → Dropdown Style), invitations awaiting a reply now appear there as well, with the same Accept, Tentative, Decline and Propose actions — and the same amber dot on the meeting row below, marking one that's still waiting.

It isn't a second implementation. Both dropdowns draw the same card, so the parts that matter can't drift apart: declining asks once and names the person who'll be told, a reply that fails says the organizer wasn't notified, and an action that can't work is absent rather than greyed out. Two copies of that would eventually disagree, and a dropdown that quietly disagrees about whether your reply was sent is worse than one that can't send it at all.
